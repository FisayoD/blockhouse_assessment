## Overview

The code calculates four OFI metrics I was asked to calculate:
- Best-Level OFI
- Multi-Level OFI
- Integrated OFI
- Cross-Asset OFI

## Requirements

- Python 3.x
- pandas
- numpy
- scikit-learn
- matplotlib

## How to Use
